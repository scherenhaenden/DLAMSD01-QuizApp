# Train-your-Brain: UI & UX Design System

This directory contains the complete design specifications, user experience tokens, and accessibility guidelines for the **Train-your-Brain** iOS application.

## Directory Index

1. [**UI Guidelines & Visual Tokens**](ui_guidelines_and_tokens.md):
   - Design philosophy and cognitive microlearning foundations.
   - Semantic color palette (Light & Dark mode tokens).
   - Dynamic Type typography scale with Apple San Francisco.
   - 4-point spacing grid and minimum touch targets (56 pt).
   - Multi-device layout strategy (iPhone vs. iPad 9th Generation 10.2").

2. [**Wireframes & Interaction Flows**](wireframes_and_flows.md):
   - Global user interaction flow diagram (Mermaid).
   - Text/ASCII wireframes for `HomeView`, `QuizView` (active and 1.0s feedback state), and `ResultView`.
   - Responsive layout rules and container max-widths.

3. [**Accessibility & Ergonomics**](accessibility_and_ergonomics.md):
   - WCAG 2.1 AA visual contrast ratios.
   - Non-color dependent feedback cues (checkmarks/crosses).
   - iOS Haptic feedback sensory mapping (`UIImpactFeedbackGenerator`).
   - VoiceOver accessibility labels, hints, and dynamic updates.
