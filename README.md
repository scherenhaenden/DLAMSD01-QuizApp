# DLAMSD01 - Apple Mobile Solution Development I

## Quiz App: Train-your-Brain

iOS quiz application developed as part of the DLAMSD01 course at IU International University of Applied Sciences.

### Overview
- Interactive quiz gameplay with multiple-choice questions
- Immediate answer evaluation and score tracking
- Built using Swift and SwiftUI

### Project Structure
- `src/`: Xcode project and Swift application source code
- `docs/`: Technical notes, requirements, and documentation
